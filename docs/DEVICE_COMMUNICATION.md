# 第二阶段设备通信说明

## 设备管理

“设备管理”可新增、编辑、删除、查询设备。设备编号不区分大小写且必须唯一。保存设备配置后会写入当前 Windows 用户的 `%LocalAppData%\IndustrialDataAnalyzer\devices.json`；重启后自动加载。编辑或删除已连接设备会先断开连接。可在设备页执行连接、断开和异常后的手动重连，也可在“实时数据采集”页启动、停止所选设备。

## 真实串口

点击“刷新可用端口”读取 Windows 报告的 COM 名称；设备暂未插入时也可手动输入端口名。通信参数为端口、波特率、数据位、停止位、校验位、流控、编码和结束符。默认值为 9600、8 数据位、1 停止位、无校验、无流控、UTF-8 和 `\n`。ASCII 也可选。结束符支持 `\r`、`\n`、`\t` 的转义写法，例如 `\r\n`。

接收端把串口字节缓存在内存中，只有收到完整结束符才产生一条报文；一次读取中的多条报文会逐条输出，跨多次读取的报文会合并。单条报文上限 64 KiB，超限会报告通信异常，以防无限缓存。发送时自动追加相同结束符。断开时取消接收并释放串口；串口 I/O 报错或端口从系统列表消失时标记异常。无协议心跳的设备若只是停止发送、但端口仍由系统报告为可用，软件无法判断其业务层是否掉线。

## 模拟设备

可选温度、重量、电压，配置最小值、最大值和采样间隔（50～3,600,000 ms）。模拟设备输出数值文本，来源在报文记录中显示为“模拟”，无需 COM 端口。新增设备时字段及单位默认随测量类型设置：温度/℃、重量/g、电压/V。模拟数据仅用于采集流程验证，不能代表真实仪器精度。

## 解析规则

每台设备解析一个数值字段，名称与单位可配置：

| 方式 | 示例报文 | 设置 |
| --- | --- | --- |
| 文本数值 | `23.5` | 整条报文是数字；默认方式 |
| 分隔符 | `T,23.5,OK` | 分隔符 `,`，字段序号 `1`（从 0 开始） |
| 正则表达式 | `T=23.5` | 表达式 `T=(?<value>[-+]?\d+(?:\.\d+)?)`，捕获组 `value` |

数值使用英文小数点并按不依赖地区设置的格式解析。解析失败保留原始报文和错误，不会导致应用退出。采集页每台设备仅保留本次运行最近 200 条、当前页面显示最近 50 条；关闭软件后这些记录清除。需要长期存储时在第三阶段接入 SQLite。

## 日志与排查

日志目录为 `%LocalAppData%\IndustrialDataAnalyzer\Logs`。连接、断开、发送、接收及解析失败会记录在滚动日志中；接收日志中的单条原文最多记录前 512 个字符。真实 COM 联机和拔插测试必须在目标设备及对应驱动环境完成；本阶段自动化测试覆盖模拟设备、配置保存、帧拼装和解析，不构成实机验收。
