# 后续开发计划

## 第一阶段：工程与界面（已完成）

.NET 10 WPF 解决方案、统一资源、Host 依赖注入、Serilog 日志、用户数据路径、异常处理、八个可导航页面和基础服务测试。页面目前仅显示空状态。

## 第二阶段：设备管理与通信

设备档案、串口参数、SerialPort 通信、真实设备连接、模拟设备、报文接收、协议解析及通信异常处理。先确定设备协议和现场硬件，再实现适配器及联机验证。

## 第三阶段：采集与存储

实时和多设备采集、缓存与批量写入、SQLite 数据库、数据完整性与恢复策略。补充断线和长时间运行测试。

## 第四阶段：监测与分析

ScottPlot 实时曲线、多指标监测、历史查询、统计指标、数据对比及异常值分析。

## 第五阶段：报警与报表

报警规则、超限报警、确认和处理记录；Excel、CSV、PDF 导出及打印。

## 第六阶段：测试与交付

完整功能、串口压力、异常断线及数据完整性测试；Windows x64 绿色免安装发布包、用户说明书和软件著作权申请材料。

每阶段完成后先验收，再进入下一阶段。第一阶段的 UI 和基础测试不能替代真实设备、数据库、导出或打印验证。
