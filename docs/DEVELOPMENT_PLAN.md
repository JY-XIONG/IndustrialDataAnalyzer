# 后续开发计划

## 第一阶段：工程与界面（已完成）

.NET 10 WPF 解决方案、统一资源、Host 依赖注入、Serilog 日志、用户数据路径、异常处理、八个可导航页面、基础服务、导航测试及 Windows 构建工作流。历史质量验证见 [第一阶段验收报告](FIRST_STAGE_ACCEPTANCE.md)。

## 第二阶段：设备管理与通信（已完成，实机联调待验）

设备档案与 JSON 本地持久化、串口参数和 COM 扫描、文本行串口收发、拆包粘包、模拟温度/重量/电压、数值/分隔符/正则解析、连接异常及手动重连、设备页和采集页联动、总览设备计数、单元测试。真实仪器的协议匹配、端口拔插和长期稳定性仍需目标硬件验证，见 [第二阶段验收报告](SECOND_STAGE_ACCEPTANCE.md)。

## 第三阶段：采集与存储（已完成，实机联调待验）

采集会话、SQLite 测量数据库、独立有界存储队列、批量事务写入、WAL、版本迁移、备份和故障恢复；历史页按设备、时间、会话分页查询。设备配置继续使用 JSON，没有迁移。见 [第三阶段验收报告](THIRD_STAGE_ACCEPTANCE.md)。

## 第四阶段：监测与分析（未开始）

实时曲线、多指标监测、统计指标、数据对比及异常值分析。基础历史记录查询已在第三阶段完成。

## 第五阶段：报警与报表（未开始）

报警规则、超限报警、确认与处理记录，Excel、CSV、PDF 导出和打印。

## 第六阶段：测试与交付（未开始）

完整功能、串口压力、异常断线、长时间运行、数据完整性测试；Windows x64 免安装发布包、用户说明和交付材料。

每阶段完成后先验收再进入下一阶段。模拟设备与自动化测试不能代替目标仪器联机验收。
